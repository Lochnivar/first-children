# Pantheon Name Worksheet (Grok)
### Printable name-review sheet — `pantheon-names-worksheet-grok.md`

*Separate from [pantheon-reference-grok.md](pantheon-reference-grok.md) and [pantheon-reference.md](pantheon-reference.md). Cold roots and domains from [four-pantheons-roster.md](four-pantheons-roster.md); current domains from the locked grid (Luck / Adulthood / Orthodoxy / Chaos, etc.).*

**How to use**

1. Print double-sided if you like; each block is one decision.
2. Circle or check **Keep** / **Alt A–C** / **Custom**.
3. Write your own theonym on the underline when none of the candidates fit.
4. Optional note line: gender, collision worry, “sounds like X,” etc.

**Naming convention (quick)**  
Semitic consonantal root → stylized vowel-fill → theonym. Not scholarly transcription; not unmodified real words. Suffixes in this file tend to be **-on**, **-iel/-el**, **-an**, or bare.

**Two kinds of alternate**

| Kind | Label | Meaning |
|---|---|---|
| Same-root theonym | **Alt A / B / C** | New surface name; root stays |
| Root swap | **Root alt 1 / 2 / …** | Cleaner root for the *current* domain + sample theonyms |

When a domain moved but the theonym didn’t, prefer a **root alt** over a same-root rename. Pick boxes cover both.

**Phonetics key**

| Symbol | Sound |
|---|---|
| **ʾ** | Glottal stop (catch in *uh-oh*) |
| **ʿ** | Pharyngeal “pressed *a*” (ayin); soft in speech, often just thickens the vowel |
| **Ḥ / ḥ** | Harsh *kh* as in German *Bach* or Scottish *loch* |
| **Ṣ / ṣ** | Emphatic *ts* (as in *tsar*), heavier than plain *s* |
| **Š / š** | *sh* as in *ship* |
| **Ṭ / ṭ** | Emphatic *t* (heavier *t*) |
| **Ś / ś** | *s* / *sh* border (here treated like *s* in *saraph*) |
| Stress | CAPS in approximations = primary stress |

**Columns**

| Label | Meaning |
|---|---|
| **Current** | Name in the locked sketches / reference right now |
| **Domain** | Portfolio label *as currently locked* (not always the old roster label) |
| **Root** | Consonantal true-name pattern *in use now* |
| **Phonetic** | How to say the root / source word |
| **Original** | Earlier theonym and/or earlier domain label, if different |
| **Alts** | Same-root theonym proposals |
| **Root alt** | Better root for this domain + sample names (where the current root stretches) |
| **Custom** | Your write-in (name and/or root) |
