Printable name-review sheet — `pantheon-names-worksheet-grok.md`

How to use

  • Print double-sided if you like; each block is one decision.
  • Circle or check Keep / Alt A–C / Custom.
  • Write your own theonym on the underline when none of the candidates fit.
  • Optional note line: gender, collision worry, “sounds like X,” etc.

Naming convention (quick)

Semitic consonantal root → stylized vowel-fill → theonym. Not scholarly transcription; not unmodified real words. Suffixes in this file tend to be -on, -iel/-el, -an, or bare.

Two kinds of alternate

KindLabelMeaning
Same-root theonymAlt A / B / CNew surface name; root stays
Root swapRoot alt 1 / 2 / …Cleaner root for the current domain + sample theonyms

When a domain moved but the theonym didn’t, prefer a root alt over a same-root rename. Pick boxes cover both.

Phonetics key

SymbolSound
ʾGlottal stop (catch in uh-oh)
ʿPharyngeal “pressed a” (ayin); soft in speech, often just thickens the vowel
Ḥ / ḥHarsh kh as in German Bach or Scottish loch
Ṣ / ṣEmphatic ts (as in tsar), heavier than plain s
Š / šsh as in ship
Ṭ / ṭEmphatic t (heavier t)
Ś / śs / sh border (here treated like s in saraph)
StressCAPS in approximations = primary stress
